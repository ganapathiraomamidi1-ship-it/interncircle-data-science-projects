# InternCircle Data Science & AI Portfolio

Five educational projects prepared for the InternCircle Data Science & AI internship.

| Project | View code | Download full package |
|---|---|---|
| 01 — Titanic EDA | [View notebook](project_01_eda_titanic/eda_titanic.ipynb) | [Download ZIP](InternCircle_Project_01_EDA_Titanic.zip) |
| 02 — Data visualization | [View notebook](project_02_visualization/titanic_visualization.ipynb) | [Download ZIP](InternCircle_Project_02_Data_Visualization.zip) |
| 03 — Sales trend analysis | [View notebook](project_03_sales_trends/sales_trend_analysis.ipynb) | [Download ZIP](InternCircle_Project_03_Sales_Trend_Analysis.zip) |
| 04 — Titanic classifier | [View notebook](project_04_classifier/titanic_classifier.ipynb) | [Download ZIP](InternCircle_Project_04_Titanic_Classifier.zip) |
| 05 — Interactive Streamlit app | [View app source](app.py) | [Download ZIP](InternCircle_Project_05_Streamlit_ML_App.zip) |

Projects 01, 02, and 04 use the public 891-row Titanic sample from [mwaskom/seaborn-data](https://github.com/mwaskom/seaborn-data/blob/master/titanic.csv). Project 03 uses deterministic synthetic e-commerce orders and does not represent real company performance.

The Streamlit app is an educational demonstration of a historical Titanic model. Its output is not a causal explanation or advice about real people.
